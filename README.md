## To run on local device
One would need the following files:
"index.html", "style.css", "script.js", and "dragon-studio-pop.mp3"
#### Steps:
Either download the whole repository as a zip file and extract on your local device.
OR 
To download particular files only, open the file, and click on download raw file.
